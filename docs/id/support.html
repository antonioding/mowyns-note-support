Bantuan dan dukungan

Diperbarui pada 2026-11-08

Catatan baru

Pilih tanggal, lalu ketuk Catatan baru. Gunakan bilah alat di bawah teks untuk menambahkan foto, rekaman, atau daftar.

Pencadangan dan migrasi

Dari Pengaturan, buka pengelolaan data, lalu pilih pencadangan dan migrasi untuk mengekspor salinan. Simpan kata sandi jika Anda mengenkripsi cadangan.

Transkrip rekaman

Aplikasi hanya meminta akses kamera atau mikrofon saat Anda mengambil foto, memindai dokumen, atau merekam suara. Anda memilih foto dan file melalui pemilih bawaan sistem. Jika izin ditolak, Anda tetap dapat menulis catatan teks. Transkripsi memerlukan izin pengenalan ucapan dan berlangsung sepenuhnya di perangkat. Jika perangkat atau bahasa tidak didukung, rekaman tetap disimpan dan aplikasi akan memberi tahu bahwa transkripsi tidak tersedia. Aplikasi tidak beralih ke pengenalan ucapan di awan. Anda dapat mencabut izin melalui pengaturan sistem.

Baru dihapus

Buka sampah dari pengaturan data untuk memulihkan catatan. Jika catatan sudah dihapus secara permanen, Anda memerlukan cadangan sebelumnya.
