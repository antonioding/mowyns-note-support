Kebijakan privasi

Diperbarui pada 2026-11-08

Gratis dan offline

Mowyns Note gratis dan tidak memerlukan akun. Tidak ada iklan, pembelian dalam aplikasi, atau langganan. Aplikasi tidak memulai koneksi internet dan tidak menggunakan layanan iklan, pelacakan, atau analitik pihak ketiga.

Aplikasi tidak mengirim catatan, lampiran, rekaman, transkrip, pengenal perangkat, atau riwayat penggunaan kepada pengembang maupun ke server mana pun. Versi ini tidak menyediakan sinkronisasi melalui iCloud atau layanan awan lainnya.

Data di perangkat

Teks catatan, gambar, rekaman, lampiran, favorit, posisi baca, dan preferensi tersimpan di dalam aplikasi pada perangkat ini. Draf rekaman yang belum ditambahkan ke catatan juga disimpan di perangkat agar dapat dipulihkan jika perekaman terputus.

Durasi penggunaan di bagian Tentang hanya dihitung di perangkat ini dan dapat Anda atur ulang. Data tersebut tidak diunggah atau dipakai untuk membuat profil pengguna.

Rekaman, transkripsi, dan izin

Aplikasi hanya meminta akses kamera atau mikrofon saat Anda mengambil foto, memindai dokumen, atau merekam suara. Anda memilih foto dan file melalui pemilih bawaan sistem. Jika izin ditolak, Anda tetap dapat menulis catatan teks.

Transkripsi memerlukan izin pengenalan ucapan dan berlangsung sepenuhnya di perangkat. Jika perangkat atau bahasa tidak didukung, rekaman tetap disimpan dan aplikasi akan memberi tahu bahwa transkripsi tidak tersedia. Aplikasi tidak beralih ke pengenalan ucapan di awan. Anda dapat mencabut izin melalui pengaturan sistem.

Cadangan, berbagi, dan layanan lain

Anda sendiri yang memulai ekspor serta pembuatan cadangan biasa atau terenkripsi. Kata sandi cadangan terenkripsi tidak disimpan dan tidak dapat dipulihkan jika terlupa. Simpan file cadangan dan kata sandinya di tempat yang aman.

Saat Anda berbagi, memilih file dari layanan file sistem, atau membuka tautan di peramban, tindakan itu ditangani oleh sistem atau aplikasi pilihan Anda. Cadangan perangkat, penyedia file awan, dan dikte papan ketik mengikuti pengaturan dan kebijakan masing-masing. Mowyns tidak mengunggah atau menyinkronkan catatan secara otomatis melalui tindakan tersebut.

Penyimpanan dan penghapusan

Catatan yang dihapus masuk ke sampah terlebih dahulu. Anda dapat memulihkannya, mengonfirmasi penghapusan permanen, atau mengosongkan sampah. Draf rekaman bisa dibuang langsung dari panel perekaman. Rekaman yang sudah disimpan dikelola bersama catatan dan lampirannya.

Di iOS, menghapus aplikasi beserta datanya juga menghapus data lokal Mowyns. Pilihan untuk melepas aplikasi sambil menyimpan dokumen dan data akan mempertahankan isi catatan. Kelola file yang sudah diekspor dan cadangan sistem di tempat masing-masing. Pengembang tidak memiliki salinan catatan Anda dan tidak dapat memulihkan data lokal yang hilang.

Pembaruan kebijakan

Jika versi mendatang mengubah cara pengelolaan data, kebijakan ini akan diperbarui dan persetujuan Anda akan diminta jika diperlukan. Kebijakan terkini selalu dapat dibaca secara offline di Pengaturan, pada bagian privasi dan penyimpanan.
