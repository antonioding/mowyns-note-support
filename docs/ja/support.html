iOS のワイヤレスデータ通信の許可ダイアログについて

2026年11月8日更新

一部の iPhone で、クイックノートや文字入力欄を開くとワイヤレスデータ通信の許可ダイアログが表示される問題を調査しています。マイクを押したり音声入力を使ったりしていなくても、表示される場合があります。ご心配とご不便をおかけしていることを心よりお詫び申し上げます。この問題を優先して調査し、できるだけ早く回避方法と修正を見つけ、検証できるよう取り組んでいます。

今回のソースコードと取得済みログの確認では、Mowyns のアプリコードが遠隔サービスにリクエストを送信した証拠や、ノート・添付ファイル・録音をアップロードした証拠は見つかっていません。iOS の文字入力・システムキーボードの音声入力コンポーネントによるネットワーク利用可否の確認処理を特定しました。これはネットワークの状態を照会する処理であり、呼び出しや許可ダイアログだけで、実際の遠隔接続やデータ送信が行われたとは判断できません。この確認処理はアプリのプロセス内で実行されることがあるため、システムはアプリ名を表示します。以上は現在の調査範囲に限った結果であり、すべてのシステムコンポーネントのネットワーク動作を完全に監査したものではありません。

このダイアログは iOS 27.0.1 で再現を確認しました。Apple 公式開発者フォーラムには、iOS 26.4、26.5、iOS 27 ベータ版での類似報告もあります。Apple の技術サポートは関連する報告を内部の問題 r.183584353 に関連付けています。本案内の更新時点で、公開の議論には修正済みの OS バージョンや公開 API による解決策の発表はありません。ダイアログを安定して解消する修正は、まだ検証できていません。

ダイアログでは「許可しない」を選んでください。端末内のテキストノートの編集と保存には影響しません。現在のアプリはそのまま残してください。ダイアログを消したり古いバージョンに戻したりするためにアプリを削除すると、端末内のノートも削除されます。必要に応じて、先に「バックアップと移行」からバックアップを書き出してください。システムキーボードの音声入力や、リンクを開く・共有する・クラウドのファイルサービスを利用するなど、ご自身で開始する操作には、それぞれの設定とポリシーが適用されます。

Mowynsを作ったきっかけ

シンプルで使いやすく、完全無料の記録ツールが欲しくて、長い間探していました。それでも自分に合うものが見つからず、Mowynsを作ることにしました。今は自分でも毎日の記録に使っています。

今日には、今日のページ

ノートを開いたとき、目の前にあるのは今日の暮らしであってほしい。カレンダーには選んだ日の記録が並び、昨日のことは昨日に残ります。振り返りたくなったら日付を選ぶか、タイムラインをたどってください。過去の記録を残しながら、新しい一日を始められます。

ノート

今日食べたものを撮って、ひと言添える。やってみたいことを書き留める。文章も写真も録音も、同じノートに残せます。

所属日付

旅行の前に、列車や座席の情報、チケットのスクリーンショット、行きたい場所をそれぞれの日付に保存。当日そのページを開けば、予定をすぐ確認できます。数日分のノートが、自分だけの簡単な旅程になります。

カレンダー

その日の一覧の一番上で下に1回引くとカレンダー、もう1回引くとクイック検索が開きます。カレンダーを閉じた状態で日付の見出しを左右にスワイプすると、前後の日に切り替えられます。

外観

テーマカラーとライト／ダーク表示を選べます。文字サイズや行間も、自分の読みやすさに合わせて調整できます。

新しいノート

「新しいノート」を選び、タイトルと本文を入力します。編集画面の下部ツールバーから写真、録音、チェックリスト、表、ファイルを追加できます。

バックアップと移行

ノートはこのデバイスに保存されます。「設定 → データ管理 → バックアップと移行」で通常・暗号化バックアップの書き出しと読み込みができます。自動同期はないため、バックアップは自分で保管してください。

録音の文字起こし

カメラやマイクの権限は、撮影、スキャン、録音を使うときだけ求めます。写真やファイルはシステムの選択画面から自分で選びます。権限を拒否しても、通常のテキストノートは利用できます。 文字起こしにはシステムの音声認識権限が必要で、処理はデバイス内でのみ行います。デバイスや言語が非対応の場合は録音を保持し、文字起こしが利用できない旨を表示します。クラウド認識には切り替えません。権限はシステム設定で取り消せます。

最近削除した項目

「設定 → データ管理 → 最近削除した項目」でノートを復元できます。完全に削除した後は、以前に書き出したバックアップが必要です。開発者はノートのコピーを持っていません。
