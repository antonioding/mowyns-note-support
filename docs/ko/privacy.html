무료 및 오프라인 사용

Mowyns는 계정, 광고, 앱 내 구입 또는 구독 없이 무료로 사용할 수 있습니다. 앱은 인터넷 연결을 시작하지 않으며 광고, 추적 또는 타사 분석 서비스를 사용하지 않습니다.

앱은 노트, 첨부 파일, 녹음, 변환된 텍스트, 기기 식별자 또는 사용 기록을 개발자나 서버에 전송하지 않습니다. 현재 버전은 iCloud 또는 다른 클라우드 동기화를 제공하지 않습니다.

기기에 저장된 데이터

노트 본문, 이미지, 녹음, 첨부 파일, 즐겨찾기, 읽던 위치 및 설정은 앱 내부에 로컬로 저장됩니다. 아직 노트에 추가하지 않은 녹음 초안도 중단 후 복구할 수 있도록 기기에 보관됩니다.

정보 화면의 사용 시간은 이 기기에서만 집계되며 직접 초기화할 수 있습니다. 업로드되거나 사용자 프로파일링에 사용되지 않습니다.

녹음, 텍스트 변환 및 시스템 권한

사진 촬영, 스캔 또는 녹음을 사용할 때만 카메라나 마이크 권한을 요청합니다. 사진과 파일은 시스템 선택 화면에서 직접 고릅니다. 권한을 거부해도 일반 텍스트 노트는 작성할 수 있습니다.

텍스트 변환에는 시스템 음성 인식 권한이 필요하며 기기 내 인식만 사용합니다. 기기나 언어가 지원되지 않으면 녹음을 유지하고 변환을 사용할 수 없다고 안내합니다. 클라우드 인식으로 전환하지 않습니다. 시스템 설정에서 권한을 철회할 수 있습니다.

백업, 공유 및 외부 서비스

일반 백업, 암호화된 백업 및 내보내기는 사용자가 직접 시작합니다. 암호화된 백업의 비밀번호는 저장되지 않으며, 잊어버리면 해당 백업을 복구할 수 없습니다. 백업 파일과 비밀번호를 안전하게 보관하세요.

직접 공유하거나 시스템 파일 서비스에서 파일을 선택하거나 노트의 링크를 브라우저로 열면 시스템 또는 선택한 앱이 해당 작업을 처리합니다. 기기 전체 백업, 클라우드 파일 서비스 및 시스템 키보드 받아쓰기는 각자의 설정과 정책을 따릅니다. 이는 Mowyns의 자동 업로드나 클라우드 동기화가 아닙니다.

보관 및 삭제

삭제한 노트는 먼저 최근 삭제된 항목으로 이동합니다. 복원하거나 확인 후 영구 삭제하거나 휴지통을 비울 수 있습니다. 녹음 초안은 녹음 패널에서 직접 폐기할 수 있습니다. 저장된 녹음은 노트 및 첨부 파일과 함께 관리됩니다.

iOS에서 앱 삭제는 앱의 로컬 데이터를 삭제하고, 앱 정리하기는 문서와 데이터를 유지합니다. 이전에 내보낸 파일과 시스템 백업은 각 저장 위치에서 별도로 관리해야 합니다. 개발자는 노트 사본을 보유하지 않으므로 잃어버린 로컬 내용을 복구할 수 없습니다.

정책 업데이트

향후 버전에서 데이터 처리 방식이 변경되면 이 안내를 업데이트하고 필요한 경우 동의를 요청합니다. 현재 안내는 설정 → 개인정보 및 저장 공간에서 언제든지 오프라인으로 읽을 수 있습니다.
