iOS 무선 데이터 접근 권한 알림 안내

2026년 11월 8일 업데이트

일부 iPhone에서 빠른 메모나 텍스트 입력란을 열 때 무선 데이터 접근 권한 알림이 나타나는 문제를 조사하고 있습니다. 마이크를 누르거나 받아쓰기를 사용하지 않아도 알림이 나타날 수 있습니다. 이로 인해 걱정과 불편을 드린 점 진심으로 사과드립니다. 이 문제를 우선적으로 조사하고 있으며, 가능한 우회 방법과 수정 방안을 최대한 빨리 찾아 검증하기 위해 노력하고 있습니다.

이번 문제의 소스 코드와 수집된 로그를 확인한 결과, Mowyns 자체 코드가 시작한 원격 요청이나 노트, 첨부 파일, 녹음이 업로드되었다는 증거는 찾지 못했습니다. 현재 증거는 iOS의 텍스트 입력 또는 시스템 키보드 받아쓰기 구성 요소가 시작하는 네트워크 사용 가능 여부 확인을 가리킵니다. 이 확인은 앱 프로세스 안에서 실행될 수 있으므로 알림에 앱 이름이 표시됩니다. 알림이 나타났다는 사실만으로 기록 내용이 업로드되었다는 뜻은 아닙니다. 이 결과는 현재 조사 범위에 한정되며, 모든 시스템 구성 요소의 네트워크 활동을 완전히 감사한 결과는 아닙니다.

Apple 공식 개발자 포럼에도 비슷한 문제가 기록되어 있으며, Apple은 관련 보고를 내부 문제 r.183584353과 연결했습니다. 이것이 Mowyns의 특정 버전에서 동작이 달라진 원인을 Apple이 확인했다는 뜻은 아닙니다. 이 안내를 업데이트한 시점까지 공개 논의에는 수정된 OS 버전이나 공개 API를 이용한 해결책이 발표되지 않았습니다. 조사는 계속되고 있으며, 안정적으로 알림을 없앨 수 있는 수정은 아직 검증되지 않았습니다.

이미 1.0.39를 설치했다면 알림에서 “허용 안 함”을 선택하세요. 로컬 텍스트 편집과 저장에는 무선 데이터 접근 권한이 필요하지 않습니다. 아직 설치하거나 업데이트하지 않았다면 추후 안내가 나올 때까지 1.0.39 설치 또는 업데이트를 미루셔도 됩니다. 현재 앱은 그대로 유지해 주세요. 이전 버전으로 되돌리려고 앱을 삭제하면 기기에 저장된 노트도 삭제됩니다. 필요하다면 먼저 “백업 및 이전”에서 백업을 내보내세요. 시스템 키보드 받아쓰기와 링크 열기, 공유, 클라우드 파일 서비스 이용처럼 사용자가 직접 시작하는 작업에는 각각의 설정과 정책이 적용됩니다.

Apple 공식 논의 읽기 · r.183584353

Mowyns를 만든 이유

간단하고 쓰기 좋으면서 완전히 무료인 기록 도구를 원했습니다. 오래 찾아도 마음에 드는 것이 없어 Mowyns를 만들었고, 지금은 저도 매일 사용하고 있습니다.

오늘을 위한 새로운 페이지

노트를 열면 오늘의 일상이 보이면 좋겠다고 생각했습니다. 달력은 선택한 날짜의 기록을 보여 주므로 어제의 기록은 어제에 남습니다. 돌아보고 싶을 때 날짜를 고르거나 타임라인을 따라가면 됩니다. 지난 기록은 보관하면서 새로운 하루를 시작할 수 있습니다.

노트

오늘 먹은 음식을 찍고 몇 마디를 적어 보세요. 해 보고 싶은 일도 가볍게 남겨 두세요. 글과 사진, 녹음을 한 노트에 함께 담을 수 있습니다.

해당 날짜

여행 전에 열차 정보와 좌석 번호, 승차권 캡처, 가고 싶은 곳을 해당 날짜에 저장하세요. 그날의 페이지를 열면 준비한 계획이 보입니다. 며칠간의 노트가 나만의 간단한 여행 일정이 됩니다.

달력

하루 목록의 맨 위에서 한 번 아래로 당기면 달력이 보이고, 한 번 더 당기면 빠른 검색이 열립니다. 달력을 접은 상태에서 날짜 제목을 좌우로 밀면 이전 날과 다음 날로 이동합니다.

화면 모드

테마 색상과 라이트 또는 다크 모드를 선택할 수 있습니다. 글자 크기와 줄 간격도 읽기 편하게 조절하세요.

새 노트

새 노트를 선택하고 제목과 본문을 입력하세요. 편집기 하단 도구 막대에서 사진, 녹음, 체크리스트, 표와 파일을 추가할 수 있습니다.

백업 및 이전

노트는 이 기기에 저장됩니다. 설정 → 데이터 관리 → 백업 및 이전에서 일반 또는 암호화된 백업을 내보내거나 가져올 수 있습니다. 자동 동기화는 제공하지 않으므로 백업을 직접 보관하세요.

녹음 텍스트

사진 촬영, 스캔 또는 녹음을 사용할 때만 카메라나 마이크 권한을 요청합니다. 사진과 파일은 시스템 선택 화면에서 직접 고릅니다. 권한을 거부해도 일반 텍스트 노트는 작성할 수 있습니다. 텍스트 변환에는 시스템 음성 인식 권한이 필요하며 기기 내 인식만 사용합니다. 기기나 언어가 지원되지 않으면 녹음을 유지하고 변환을 사용할 수 없다고 안내합니다. 클라우드 인식으로 전환하지 않습니다. 시스템 설정에서 권한을 철회할 수 있습니다.

최근 삭제된 항목

설정 → 데이터 관리 → 최근 삭제된 항목에서 노트를 복원할 수 있습니다. 영구 삭제 후에는 이전에 내보낸 백업이 필요합니다. 개발자는 노트 사본을 보유하지 않습니다.
